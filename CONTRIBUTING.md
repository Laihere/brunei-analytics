# Contributing

This is a personal project by Muhd Lai Razi, built with AI assistance (Claude by Anthropic).
It is public so that readers can see how each case study was made, but it is not open to
contributions: pull requests, issues and suggested changes are not accepted.

If you spot a mistake in a case study or the data, or have a question, please email
laihere281@gmail.com.
